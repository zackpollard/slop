### Modelling notes for this user
- **One plug-in device per household.** At 800 W into a ≥800 W server base load, nearly all output is used on site. The value is then Σ(PV_AC × Agile import price), including slots where the price is negative.
- **Export.** It only matters if the base load drops below PV output. It pays only on the Octopus kit (Prime: 16p from 16:00 to 19:00, 9p otherwise).
- **Batteries mean the hardwired G98 route.** That brings:
  - install cost and possibly a consumer unit upgrade;
  - 0% VAT only if the installer supplies the equipment;
  - no 800 W, 2000 Wp or one-device constraints, only 16 A per phase in total;
  - batteries large enough for this load: STREAM 5000 / AC 5000, Solarbank 4 Pro or SolarFlow 2400.
- **Plug-in kit plus a separate battery** should be shown as non-compliant, because the IPS instructions forbid using the device with battery storage.
