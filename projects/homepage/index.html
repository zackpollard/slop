slop.

A collection of small projects and experiments by Zack Pollard.

What is this?

slop is a monorepo and home for various small apps, tools, and experiments. Each project lives in its own space and gets deployed as a subdomain under slop.zackpollard.pro.

Projects span different languages and frameworks — whatever fits the problem best. This page serves as the index and directory for everything hosted here.

Projects

Roof Calculator

Satellite map-based roof measurement tool. Draw polygons over roof sections, set pitch angles, and calculate true area with waste allowance.

D&D Encounter Generator

Combat encounter generator using D&D 2024 rules. Configure party size, level, and difficulty with environment, creature type, and theme filters.

Cron Translator

Paste a cron expression, get a human-readable description, visual timeline, and list of upcoming runs.

Subnet Calculator

Enter an IP address and CIDR prefix to get full subnet breakdown with binary visualization and address space map.

JSON Carpenter

Format, validate, and diff JSON with syntax highlighting, collapsible tree view, and path copying.

Flip 7 Scoreboard

Score tracker for the Flip 7 press-your-luck card game. Track players, rounds, modifiers, and race to 200 points.

UNO No Mercy Scoreboard

Score tracker for UNO Show 'Em No Mercy. Count cards, track knockouts, and race to 1,000 points across hands.

Exploding Kittens Assistant

Game tracker, card reference, and draw probability calculator for Exploding Kittens with all expansions.

Herd Mentality

Digital companion for Herd Mentality. Displays questions, collects secret answers via pass-and-play, reveals the herd, and tracks the Pink Cow.

Texas Hold'em

Multiplayer Texas Hold'em poker on your phone. Create a table, share the code, and play with friends via peer-to-peer WebRTC.

Cards Against Humanity

Peer-to-peer party game for horrible people. Create or join a game with a code — no server needed.

Waze Beeps

A beeps-only Waze sound pack. One short beep for every turn, plus loud, obvious alerts for speed cameras and police. Preview and download as WAV.
