# Herd Mentality

A digital companion for the Herd Mentality party game. Displays questions, collects answers secretly via pass-and-play, then reveals results — highlighting the herd (majority answer) and tracking who holds the Pink Cow.

## Features

- **100+ built-in questions** across 7 categories (favourites, pop culture, animals, people, hypothetical, word association, opinions)
- **Category filters** to customise the question pool
- **Custom questions** — type your own at any time
- **Pass-and-play answer collection** with a ready screen between players
- **Automatic herd detection** with tie-breaking (ties = no herd)
- **Pink Cow tracking** — randomly assigned to an odd-one-out each round
- **Mobile-friendly** responsive design
