# Picture credits

Every picture in this project is used under a free licence and is credited on
screen when its question is played. Files are named opaquely (`logo-04.png`,
not `hsbc.png`) so the answer is not visible in the browser's network tab.

Brand marks are trademarks of their owners and appear here only to identify
them, which is what a quiz question does.
